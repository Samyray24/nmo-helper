# NMO Helper 5.6.2

Выпуск добавляет проверку полного сценария автоответа и обновляет готовые пакеты для браузеров.

- Сквозной тест запускает собранное расширение в Playwright Chromium на изолированной странице с разметкой НМО. Он проверяет точные варианты одиночного и множественного ответа, переход к следующему вопросу, завершение теста и действие кнопки «Стоп».
- Инструкция по установке и [протокол проверки браузеров](BROWSER_VERIFICATION.md) теперь отделяют подтверждённые проверки от неподтверждённых сред.
- Обе Firefox-сборки временно установились в изолированном Firefox 155; проверка интерфейса и Astra Linux ещё требуется.
- Все архивы и папки «ГОТОВЫЕ ВЕРСИИ» пересобраны для версии 5.6.2. Firefox XPI остаются неподписанными; [порядок подписи](MOZILLA_SIGNING.md).

Тестовая страница имитирует разметку портала. Проверка с настоящим аккаунтом и живым тестом НМО не проводилась.
