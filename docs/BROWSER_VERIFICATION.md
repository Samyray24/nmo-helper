# Проверка браузеров для NMO Helper 5.6.2

| Среда | Проверка | Результат |
|---|---|---|
| Playwright Chromium, Windows | Загрузка распакованного расширения, панель, popup, фон, полный автоответ и «Стоп» | Пройдено на локальной тестовой странице |
| Microsoft Edge, Windows | Загрузка распакованного расширения из временного профиля, popup и панель | Пройдено на этом компьютере |
| Google Chrome, Windows | Загрузка через флаги командной строки Playwright | Не удалось проверить этим способом: браузер не запустил фоновый процесс расширения |
| Яндекс Браузер, Windows | Загрузка через флаги командной строки Playwright, с окном и без окна | Не удалось проверить этим способом: фоновый процесс расширения не запустился |
| Firefox 155, Windows | Временная установка распакованной MV3-сборки через `web-ext run` в изолированном профиле; `web-ext lint` | Установка прошла, 0 ошибок и 14 предупреждений валидатора; интерфейс не проверялся |
| Firefox 155, Windows | Временная установка распакованной ESR/MV2-сборки через `web-ext run` в изолированном профиле; `web-ext lint` | Установка прошла, 0 ошибок и 21 предупреждение валидатора; интерфейс не проверялся |
| Firefox ESR на Astra Linux | Установка в целевой системе | Требует машины с Astra Linux и подходящим Firefox ESR |

Команда `npm run test:e2e` проверяет расширение в тестовом Chromium. Тест `tests/e2e/quiz-flow.spec.ts` использует локальную страницу, повторяющую основные элементы теста НМО, и искусственные ответы в локальной базе. Он не входит в настоящий аккаунт и не подтверждает работу на всех текущих страницах портала.

Для ручной проверки Chrome или Яндекс Браузера откройте страницу расширений и установите пакет по [инструкции](../INSTALL.md). Проверьте карточку расширения, popup, появление панели после обновления вкладки НМО и диагностическое окно. Для проверки автоответа используйте только тест, который вы вправе проходить, и сначала экспортируйте настройки и локальную базу.

Playwright [указывает](https://playwright.dev/docs/chrome-extensions), что актуальные Google Chrome и Microsoft Edge отключили флаги командной строки для загрузки расширений. Поэтому отсутствие фонового процесса при таком запуске само по себе не доказывает дефект пакета.

Валидатор Mozilla предупредил, среди прочего, о необходимости декларации передачи данных для новых дополнений AMO. Перед отправкой пакетов на подпись это поле нужно заполнить по фактическому поведению расширения и повторно проверить пакет.
