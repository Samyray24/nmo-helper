# Комплект для подписи Firefox

Архивы в папке «05 - Firefox - комплект для подписи Mozilla» ещё НЕ подписаны и не являются подтверждением одобрения Mozilla.

- `mozilla-modern-…-UNSIGNED.zip`: Firefox 140+, Manifest V3.
- `mozilla-esr-…-UNSIGNED.zip`: Firefox ESR 102+, Manifest V2; кандидат для Astra Linux.
- `mozilla-sources-….zip`: читаемые исходники и зависимости по lock-файлу для проверки Mozilla.

1. Войти в свой аккаунт на https://addons.mozilla.org/developers/ и выбрать отправку нового дополнения.
2. Для распространения через свои файлы выбрать самостоятельное распространение (unlisted).
3. Загрузить соответствующий UNSIGNED.zip. Это два разных дополнения с отдельными идентификаторами Samyray24.
4. На запрос исходников предоставить mozilla-sources ZIP и инструкции сборки ниже.
5. Дождаться проверки, скачать подписанный XPI и только затем заменить пользовательский неподписанный пакет.

Пароль от аккаунта не нужен в коде или архиве. Пакет не был отправлен на подпись автоматически.
Переход с локальной сборки на подписанную с другим ID требует экспорта базы и настроек и последующего импорта.
Минимальная версия в manifest — техническое требование, а не подтверждение тестирования на всех версиях.

## Сборка для проверяющего

Node.js 22, npm. В корне распакованных исходников:

```
npm ci
npm run build
node scripts/package-mozilla.cjs
```

Скрипт берёт dist/firefox-store и dist/firefox-legacy, заменяет только ID на отдельные ID этого проекта и создаёт архивы. Никакой загрузки исполняемого кода во время работы расширения нет. Сборка содержит React и PDF-парсер; minified JS проверяется по исходникам.

Расширение извлекает тему, вопрос и варианты на edu.rosminzdrav.ru, обращается к поисковым базам и выбранному AI-провайдеру. Отправка результатов теста регулируется отдельным согласием. Для проверки UI можно открыть тестовую страницу из tests/e2e; действительный аккаунт НМО в комплект не включён.
