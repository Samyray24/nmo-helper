# NMO Helper 5.6.1

Обновление стабильности поиска и бесплатного AI.

- Бесплатный AI получает общий предел ожидания 120 секунд. Лимит каждого следующего запроса уменьшается на уже потраченное время, включая получение списка моделей AI Horde.
- Поиск в основных источниках и загрузка страниц ответов прерываются через 15 секунд. Запросы дополнительных источников уже имели такой предел.
- Страница ответов без распознанных вопросов и вариантов больше не сохраняется как успешный результат. После трёх таких страниц источник временно пропускается на две минуты. Пустая поисковая выдача остаётся допустимым результатом.
- Если первая страница третьего источника недоступна, дополнительные страницы не запрашиваются.

Готовые архивы и распакованные варианты обновлены для Chromium, Яндекс Браузера, Firefox, Firefox ESR и Safari. Firefox-архивы остаются неподписанными: для обычной установки требуется подпись Mozilla. Подготовленные файлы для отправки в AMO и исходники находятся в релизе; [инструкция по подписи](MOZILLA_SIGNING.md).
