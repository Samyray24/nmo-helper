# NMO Helper 5.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Сделать автоматический поиск объяснимым и восстанавливаемым, добавить AI-резерв, локальную базу, диагностику, режимы автоматизации и безопасные разрешения во всех поддерживаемых браузерах.

**Architecture:** Существующие загрузчики остаются адаптерами источников. Новые независимые модули отвечают за принятие решения, постоянную сессию, локальную IndexedDB-базу, диагностику и возможности браузера; React-компоненты только связывают эти модули с интерфейсом.

**Tech Stack:** TypeScript 6, React 19, WebExtension APIs, IndexedDB, fflate, Vitest, Testing Library, esbuild/Sass.

**Spec:** `docs/superpowers/specs/2026-09-22-nmo-helper-5.3-design.md`

## Global Constraints

- Поддерживать Chromium MV3, Firefox MV3, Firefox Store MV3 и Firefox ESR MV2 с `strict_min_version: 102.0`.
- Не отправлять неизвестные вопросы без явного согласия пользователя.
- Не включать API-токены, cookies и полный текст вопроса в диагностический экспорт по умолчанию.
- Низкая уверенность и конфликт источников не должны вызывать автоматический клик.
- Сохранять текущие настройки и мигрировать boolean `autoSolveTests` в новый режим.
- Готовая версия — `5.3.0`; все архивы должны иметь корректные manifest и SHA-256.
