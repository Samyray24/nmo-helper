# NMO Helper 5.5.0

## Изменения

- Проверка стабильных выпусков в Samyray24/nmo-helper, ссылки на изменения и пакет своего браузера. Ошибка сети отличается от актуальной версии. Установка обновления вручную.
- Проверка реально отмеченных вариантов до перехода. «Стоп» доступен в полной и свёрнутой панели. Ошибка выбора или перехода отключает автопрохождение; исчезновение вопроса больше не считается успешным переходом.
- Редактор локальной базы: поиск, дата, происхождение, изменение выбранных ответов и удаление записи. Противоречия сохраняются и блокируют автоматический выбор до ручного разрешения.
- Резервная копия базы, неизвестных вопросов и настроек интерфейса/задержек без ключей AI и пользовательских URL. Восстановление добавляет записи и требует перезагрузки страницы; автоматизация после неё выключена.
- Статусы запросов по источникам: сеть, таймаут, HTTP, ограничение запросов, пустая поисковая выдача.
- Светлая/тёмная тема, короткие сообщения свёрнутой панели, видимый фокус клавиатуры, ограничение высоты и ширины панели. CSS больше не меняет box-sizing всей страницы НМО.
- Ключи AI читаются и записываются через фоновую часть: исправлен доступ к storage.session из content scripts. На старом Firefox без session используется локальное хранилище расширения.
- AI-ответы отмечены как ответы модели без выдуманного процента достоверности в подписи. Исправлена отмена AI-запроса при собственном переходе в состояние «поиск».
- Отдельный комплект для подписи Mozilla: архивы для Firefox 140+ и ESR 102+, исходники и инструкция.

## Что проверено

Автоматические тесты Vitest, TypeScript, ESLint; сборка всех четырёх manifest-вариантов; целостность архивов, CRX3 и SHA-256.

В Windows проверяется панель в установленном Chrome (1366×768 и 1024×768) и настоящее расширение в отдельном Chromium-профиле: фоновая часть, session storage, сохранение темы, масштаб 125%/200%. В браузерных тестах используется локальный тестовый HTML вместо действительного экзамена НМО. Полное прохождение реального теста не проверялось.

Firefox ESR, Яндекс Браузер и Astra Linux в этой среде не установлены: успешная сборка для них не заменяет проверку на этих браузерах. Совместимость ниже Firefox 102 не заявляется.

## Установка

Пакеты на компьютере: `ГОТОВЫЕ ВЕРСИИ/01 - Windows` и `02 - Linux`. Выберите папку браузера, затем прочитайте инструкцию внутри. GitHub: Releases, выпуск v5.5.0.

Перед заменой версии: вкладка «База» → «Управление данными» → «Сохранить базу и настройки». Ключи AI в копию не входят.

Firefox-пакеты пока неподписанные. Комплект `05 - Firefox - комплект для подписи Mozilla` нужно отправить через свой аккаунт Mozilla. Подписанный выпуск и автоматическое магазинное обновление пока не опубликованы. [Порядок подписи](MOZILLA_SIGNING.md).
