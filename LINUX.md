# 🐧 Установка NMO Helper в Linux и Astra Linux

📖 **[Полная инструкция со скриншотом и решением ошибок](https://github.com/Samyray24/nmo-helper/blob/main/INSTALL.md)** · 📦 **[Последний выпуск](https://github.com/Samyray24/nmo-helper/releases/latest)**

Терминал, Node.js и npm для установки готового расширения не нужны. Потребуются браузер и обычный менеджер архивов.

## 📦 Скачивание

1. Откройте последний выпуск и раскройте **Assets**.
2. Скачайте `nmo-helper-linux-<версия>.tar.gz` или `nmo-helper-all-browsers-<версия>.zip`.
3. Распакуйте архив в постоянное место, например в папку `nmo-helper` внутри домашнего каталога.
4. Откройте распакованную папку: внутри должны быть `chromium`, `firefox` и `firefox-esr`. В TAR-архиве они находятся внутри `nmo-helper-linux-<версия>`.

## 🌐 Chromium / Chrome

1. Вставьте `chrome://extensions` в адресную строку.
2. Включите **«Режим разработчика»** на странице расширений. Это не инструменты F12.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку **`chromium`**, внутри которой непосредственно лежит `manifest.json`.
5. Откройте или обновите страницу НМО.

Не перемещайте и не удаляйте папку после установки. Для других Chromium-браузеров [адреса страниц и подробные шаги приведены здесь](https://github.com/Samyray24/nmo-helper/blob/main/INSTALL.md#chromium).

## 🦊 Firefox / Firefox ESR на Астре

Узнайте версию: **☰ → Справка → О Firefox**.

| Версия браузера | Папка |
|---|---|
| 140 и новее | `firefox` |
| 102–139, включая ESR 102 / 115 / 128 | `firefox-esr` |
| Ниже 102 | Подходящей сборки в комплекте нет |

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите **файл `manifest.json`** из подходящей папки.
4. Откройте или обновите страницу НМО.

> ⚠️ Пакеты пока не подписаны Mozilla. Это временная установка до перезапуска Firefox. Перед перезапуском экспортируйте важную локальную базу. Для постоянной установки требуется подписанный пакет; переименование ZIP в XPI не заменяет подпись.

Поддержка заявлена по настройкам сборки; реальные проверки на Astra Linux и во всех версиях Firefox пока не выполнены. В организации установка может быть ограничена администратором.

## ⏸️ Первый запуск и обновление

Для новой установки полное автопрохождение включено по умолчанию. Нажмите **«Стоп»** и выберите в настройках **«Осторожный — подсветка»**, если сначала хотите ознакомиться с работой расширения.
