# NMO Helper в Linux

В комплекте текущая изменённая сборка: исправления ошибок и автоматический поиск
в пяти дополнительных базах. Node.js для установки готового расширения не нужен.
Расширение состоит из JavaScript и ресурсов браузера, без нативных исполняемых файлов.

## Chrome / Chromium

1. Распакуйте `nmo-helper-linux-5.3.0.tar.gz` через менеджер архивов.
2. Переместите распакованную папку в постоянное место, например `~/nmo-helper`.
3. Откройте `chrome://extensions` и включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите вложенную папку `chrome`.
5. Откройте или обновите страницу теста на https://a.edu.rosminzdrav.ru.

После установки сохраняйте папку расширения. Для обновления замените её содержимое,
нажмите кнопку обновления расширения в `chrome://extensions` и обновите страницу НМО.

[Официальная инструкция Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

## Firefox 140 и новее

Эта изменённая сборка не подписана Mozilla. Для проверки:

1. Распакуйте архив.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение».
4. Выберите файл `firefox/manifest.json` внутри распакованной папки.
5. Откройте или обновите страницу теста НМО.

Дополнение загружается до перезапуска Firefox. Для постоянной установки этой версии
нужно отдельно получить подпись Mozilla. Магазинная версия и старый подписанный XPI
из исходного репозитория не содержат наших новых изменений.

[Официальная инструкция Firefox](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

## Сборка из исходников

Установите Node.js 24 LTS, npm и `tar`, затем в каталоге проекта выполните:

```bash
npm ci
npm run package:linux
```

Готовый архив появится в `releases/`. Исходный проект с нашими изменениями находится
в локальной копии; скачивание исходного GitHub-репозитория не добавит эти изменения.

Пакет собран и проверен на Windows. Запуск в браузере под Linux ещё не проверен.
