# Подготовка к магазинам браузеров

Готовые локальные пакеты находятся в `ГОТОВЫЕ ВЕРСИИ`. Они устанавливаются без
публикации в магазине и подходят для проверки всех функций.

Для автоматического обновления через магазин нужны отдельные учётные записи
разработчика и ручная проверка площадки:

- Firefox Add-ons: используйте сборку `dist/firefox-store` и исходный код этого репозитория.
- Chrome Web Store: используйте содержимое `dist/chrome` после проверки политики доступа к сайтам с ответами.
- Microsoft Edge Add-ons: используется та же Chromium-сборка.
- Opera Add-ons: используется та же Chromium-сборка.
- Safari: требуется macOS, Xcode, конвертация WebExtension и подпись Apple.

GitHub Release содержит готовые ZIP/XPI/CRX для ручной установки. Неподписанный
Firefox XPI обычно устанавливается только временно через `about:debugging`; для
постоянной обычной установки нужна подпись Mozilla.
