# Установка NMO Helper в Windows и Linux

Один и тот же пакет содержит все наши исправления и пять дополнительных баз.
Для установки не требуются Node.js, npm или отдельная программа.

## Яндекс Браузер — установка файла расширения

1. Скопируйте `nmo-helper-yandex-windows-linux-5.4.0.crx` на нужный компьютер.
2. Откройте в Яндекс Браузере `browser://tune`.
3. Перетащите файл `.crx` в окно этой страницы и подтвердите установку.
4. Откройте или обновите страницу теста НМО: https://a.edu.rosminzdrav.ru.

Файл упакован в CRX3. После установки он появится в разделе «Из других источников».
Локальный пакет не подключён к автоматическим обновлениям: обновлённый файл нужно
будет установить вручную. При повторной сборке используется тот же локальный ключ.

[Официальная инструкция Яндекса](https://browser.yandex.ru/help/ru/personalization/extension#new-extension).

## Установка из ZIP — Яндекс / Chrome / Chromium

1. Распакуйте `nmo-helper-yandex-windows-linux-5.4.0.zip` в постоянную папку.
2. Откройте `browser://extensions` в Яндексе или `chrome://extensions` в Chrome/Chromium.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
5. Обновите страницу теста НМО.

Сохраняйте эту папку после установки. Для обновления замените её содержимое,
нажмите «Обновить»/кнопку перезагрузки расширения и обновите страницу НМО.
Если раньше была установлена другая копия NMO Helper, отключите её, чтобы панели
и автоматические действия не дублировались.

## После установки

В режиме «Авто» расширение сначала проверяет прежние базы. Если нет уверенного
совпадения, ищет в пяти новых базах по теме курса и тексту вопроса. Для AI через
платный или собственный endpoint нужны настройки соответствующего провайдера.
PDF загружается пользователем локально.

Автоответ в новой установке включён: он выбирает надёжно найденный ответ,
переходит к следующему вопросу и подтверждает завершение теста. При слабом
совпадении или конфликте баз автоклик для вопроса не выполняется.

## Сборка пакета

В локальной копии проекта с нашими изменениями:

```bash
npm ci
npm run package:yandex
```

Для упаковки нужен установленный Chrome или Chromium. Путь к исполняемому файлу
можно задать переменной окружения `CHROME_BIN`. Готовые `.crx` и `.zip` появятся
в `releases/`. Закрытый ключ хранится отдельно в `~/.codex/nmo-helper-signing/`,
не входит в архив и нужен для последующих обновлений с тем же идентификатором.

Пакеты проверены на Windows. Установка в Яндекс Браузере и запуск под Linux
ещё не проверены на реальных браузерах.
