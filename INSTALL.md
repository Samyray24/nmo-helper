# 🚀 Как установить NMO Helper — версия Samyray24

Пошаговая инструкция для **Windows, Linux и Astra Linux**. Выберите свой браузер — программировать, устанавливать Node.js или запускать команды в терминале не нужно.

**[📦 Скачать последний выпуск](https://github.com/Samyray24/nmo-helper/releases/latest)** · **[🐞 Сообщить о проблеме](https://github.com/Samyray24/nmo-helper/issues)**

> 💡 Расширение устанавливается в браузер. Это не программа `.exe` и не отдельное приложение Linux.
>
> 🦊 Пакеты Firefox сейчас **не подписаны Mozilla**: доступна временная установка до перезапуска браузера. Подробности ниже.

## 📦 1. Что скачать

1. Откройте **[последний выпуск на GitHub](https://github.com/Samyray24/nmo-helper/releases/latest)**.
2. Прокрутите до **Assets** — это список файлов выпуска. Если он свёрнут, нажмите на заголовок.
3. Скачайте файл по таблице. Вместо `<версия>` в имени будет номер выпуска, например `5.5.1`.

| Ваш браузер / задача | Нужный файл | Что делать дальше |
|---|---|---|
| 🌐 Chrome, Chromium, Edge, Brave, Opera, Vivaldi на Windows или Linux | `nmo-helper-chromium-<версия>.zip` | Распаковать и [загрузить папку](#chromium) |
| 🔴 Яндекс Браузер на Windows или Linux | `nmo-helper-yandex-windows-linux-<версия>.crx` | [Перетащить CRX в браузер](#yandex) |
| 🔴 Яндекс: установка из папки | `nmo-helper-yandex-windows-linux-<версия>.zip` | Распаковать и [загрузить папку](#chromium) |
| 🦊 Firefox, в том числе на Astra Linux | `nmo-helper-all-browsers-<версия>.zip` | Выбрать папку `firefox` или `firefox-esr` по [инструкции Firefox](#firefox) |
| 🐧 Все Linux-варианты одним файлом | `nmo-helper-linux-<версия>.tar.gz` | Распаковать; внутри `chromium`, `firefox`, `firefox-esr` |
| 🧰 Все браузерные варианты одним файлом | `nmo-helper-all-browsers-<версия>.zip` | Распаковать и выбрать нужную папку |

**Не запутайтесь в остальных файлах:**

| Файл | Для чего он |
|---|---|
| `Source code (zip)` / `Source code (tar.gz)` | Исходный код для разработчиков. Для обычной установки выбирайте готовый пакет выше |
| `nmo-helper-firefox-…-unsigned.xpi` | Неподписанный Firefox-пакет. Он не равнозначен дополнению из магазина |
| `mozilla-…-UNSIGNED.zip`, `mozilla-sources-….zip` | Комплект для отправки на подпись Mozilla, не основной способ установки |
| `nmo-helper-safari-source-….zip` | Исходники для разработчика под macOS/Xcode. Готовой установки Safari пока нет |
| `SHA256SUMS…txt` | Контрольные суммы для проверки целостности скачанных файлов |

📌 **Статус совместимости:** интерфейс и установленное расширение проверялись в Chrome/Chromium на Windows. Пакеты для остальных перечисленных браузеров собраны, но Яндекс, Firefox и Astra Linux ещё требуют проверки на реальных установках. Firefox ниже 102, Internet Explorer и мобильные браузеры не поддерживаются этим комплектом.

<a id="chromium"></a>
## 🌐 2. Chrome, Chromium, Edge, Brave, Opera и Vivaldi

### Шаг 1 — распакуйте архив

- **Windows:** нажмите правой кнопкой на ZIP → **«Извлечь все…»**.
- **Linux:** откройте архив менеджером архивов → **«Распаковать» / «Извлечь»**.

Сохраните файлы в постоянной папке, например `Документы/NMO Helper` или `~/nmo-helper`. **Не удаляйте и не перемещайте её после установки:** браузер загружает расширение из этой папки.

### Шаг 2 — откройте страницу расширений

Скопируйте подходящий адрес **в адресную строку браузера** и нажмите **Enter**. Вводить его в поиск Яндекса или Google не нужно.

| Браузер | Адрес страницы |
|---|---|
| Google Chrome / Chromium | `chrome://extensions` |
| Microsoft Edge | `edge://extensions` |
| Brave | `brave://extensions` |
| Opera | `opera://extensions` |
| Vivaldi | `vivaldi://extensions` |
| Яндекс Браузер — установка из папки | `browser://extensions` |

### Шаг 3 — включите режим разработчика

Найдите переключатель **«Режим разработчика» / Developer mode** и включите его.

- В Chrome переключатель обычно расположен **справа сверху**.
- В Edge он находится **в левой части страницы**; при узком окне сначала откройте боковое меню ☰.
- В других Chromium-браузерах расположение зависит от версии: ищите переключатель на странице расширений, обычно в верхней части.

> 🔧 Это переключатель на странице расширений. Открывать инструменты разработчика клавишей F12 не нужно.

### Шаг 4 — выберите правильную папку

Нажмите **«Загрузить распакованное расширение» / Load unpacked**. В некоторых переводах кнопка называется **«Загрузить распакованное»**.

Выберите **папку, внутри которой непосредственно лежит `manifest.json`**:

```text
📁 NMO Helper         ← выбирайте эту папку
   ├── manifest.json
   ├── content.js
   ├── background.js
   ├── popup.html
   └── icons/
```

Если скачан общий комплект, нужная папка называется **`chromium`**. Если скачан отдельный Chromium ZIP, `manifest.json` находится среди распакованных файлов; название внешней папки задаёт ваш архиватор.

**Выбирайте папку, а не ZIP и не сам `manifest.json`.** После загрузки появится карточка **NMO Helper**. Переключатель на карточке должен быть включён.

### Шаг 5 — откройте НМО

Откройте [портал НМО](https://a.edu.rosminzdrav.ru/) или обновите уже открытую страницу. Расширение не добавляет панель на GitHub, поисковых сайтах или внутренней странице настроек браузера.

✅ Карточка расширения появилась — переходите к [первому запуску](#first-start).

Официальные примеры: [Chrome — загрузка из папки](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked), [Edge — локальная установка](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading).

<a id="yandex"></a>
## 🔴 3. Яндекс Браузер

### Вариант А — файл CRX

1. Скачайте `nmo-helper-yandex-windows-linux-<версия>.crx` из **Assets** выпуска.
2. Откройте в Яндекс Браузере адрес `browser://tune`.
3. Откройте папку со скачанным файлом рядом с браузером.
4. **Перетащите `.crx` на открытую страницу дополнений**, а не в адресную строку.
5. Если браузер покажет запрос установки, проверьте название и подтвердите добавление.
6. Обновите страницу НМО.

Для этого способа предварительно включать режим разработчика не требуется. Яндекс описывает установку собственного CRX3 в [официальной справке](https://www.yandex.ru/support/browser/ru/personalization/extension).

### Вариант Б — из распакованной папки

Если CRX не устанавливается, попробуйте ZIP этого же выпуска:

1. Распакуйте `nmo-helper-yandex-windows-linux-<версия>.zip`.
2. Откройте `browser://extensions`.
3. Включите **«Режим разработчика»**.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с `manifest.json`.

Если браузер сообщает об ограничении организации, обратитесь к администратору. Переключение способа установки не отменяет эти ограничения.

<a id="firefox"></a>
## 🦊 4. Firefox и Astra Linux

### Сначала узнайте версию Firefox

Откройте **☰ → Справка → О Firefox**. Запишите номер, например `128.12.0esr`.

| Версия Firefox | Папка из общего ZIP / Linux-комплекта |
|---|---|
| **140 и новее** | `firefox` |
| **102–139**, включая ESR 102/115/128 | `firefox-esr` |
| **Ниже 102** | Подходящей сборки в этом комплекте нет |

Это минимальные требования сборок, а не обещание работы на каждой промежуточной версии. На служебной Astra Linux возможность установки также зависит от настроек организации.

### Временная установка — доступна сейчас

1. Скачайте и распакуйте `nmo-helper-all-browsers-<версия>.zip`. На Linux можно использовать комплект `.tar.gz`.
2. В адресной строке Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Если открылось меню отладки, выберите **«Этот Firefox» / This Firefox**.
4. Нажмите **«Загрузить временное дополнение…» / Load Temporary Add-on**.
5. Откройте папку из таблицы выше и выберите **файл `manifest.json`**.
6. Обновите страницу НМО.

💡 В Firefox выбирается **файл**, а в Chrome/Chromium — **папка**. Это частая причина путаницы.

### Что будет после закрытия браузера

Временное дополнение удаляется при перезапуске Firefox. Для следующего запуска нужно повторить загрузку через `about:debugging`. Перед перезапуском экспортируйте важную базу и настройки — не рассчитывайте на временную установку как на резервную копию. [Как работает временная установка](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

### Постоянная установка — после подписи Mozilla

Текущие XPI помечены **`unsigned`**, то есть «неподписанный». Они могут быть отклонены обычным Firefox при установке через `about:addons`. Это не исправляется переименованием ZIP в XPI.

Когда будет опубликован **подписанный** пакет этой версии, его можно будет установить через `about:addons` → ⚙ → **«Установить дополнение из файла»**. Сейчас подписанного выпуска Samyray24 нет. Дополнение исходного автора из магазина не содержит автоматически всех наших изменений.

Комплект для получения подписи подготовлен отдельно: [инструкция для сопровождающего](https://github.com/Samyray24/nmo-helper/blob/main/docs/MOZILLA_SIGNING.md). Пользователю не нужно отправлять пакет на подпись самостоятельно.

## 🎉 5. Первый запуск и настройки

### Где искать расширение

- **Значок браузера:** откройте меню расширений 🧩 и выберите **NMO Helper**. При желании закрепите значок на панели инструментов.
- **Панель на странице:** откройте портал НМО. Если видна маленькая свёрнутая плашка, нажмите кнопку разворачивания.
- **Наша версия:** в окне по нажатию на значок написано **«Версия Samyray24»**.

![Окно расширения: версия Samyray24](https://raw.githubusercontent.com/Samyray24/nmo-helper/main/docs/images/popup-samyray24.png)

### Сначала выберите подходящий режим

> ⏸️ В новой установке полное автопрохождение включено по умолчанию. Чтобы сначала ознакомиться с панелью, нажмите **«Стоп»** до работы с вопросами или откройте ⚙ **«Настройки» → «Режим автоматизации»** и выберите осторожный режим.

| Режим автоматизации | Что делает расширение |
|---|---|
| 🟢 **Осторожный — подсветка** | Показывает найденные ответы; варианты и переходы нажимаете вы |
| 🟡 **Обычный — выбрать ответ** | Отмечает найденные варианты; переходите дальше вы |
| 🔵 **Полный — пройти тест** | Выбирает ответы, переходит дальше и может подтвердить завершение теста |

**«Стоп»** отключает автоматические выборы и переходы. При непроверенном выборе, конфликте локальных ответов или сбое перехода расширение также останавливает автоматизацию. Найденный ответ всё равно может быть ошибочным — проверяйте источник и формулировку вопроса.

### Для чего нужны вкладки

| Вкладка | Назначение |
|---|---|
| ⚡ **Авто** | Поиск ответа с использованием доступных баз |
| 🌐 **Сайты** | Работа с поиском по сайтам-источникам |
| 🤖 **AI** | Обращение к выбранному AI-провайдеру |
| 📄 **PDF** | Поиск в вашем локальном PDF-документе |
| 🗃️ **База** | Импорт, поиск и редактор ответов, резервные копии, состояние источников |

**Нужен ли API-ключ?** Для установки и поиска по базам — нет. Бесплатный AI-режим не требует личного ключа, но зависит от доступности внешнего сервиса. Для ProxyAPI или собственного провайдера нужны его настройки и, как правило, ключ. AI-резерв можно выключить в дополнительных настройках автоматизации.

🌗 Светлая и тёмная темы переключаются кнопкой ☀/☾ в верхней части панели.

## 🔄 6. Обновление и резервная копия

Расширение проверяет выпуски на GitHub и может предложить скачать новую версию. **Сам файл расширения пока обновляется вручную.**

### Перед обновлением

1. Нажмите **«Стоп»**, если автоматизация работает.
2. Откройте **«База» → «Управление данными» → «Сохранить базу и настройки»**.
3. Сохраните скачанный JSON в надёжном месте.

Копия включает ответы, неизвестные вопросы и поддерживаемые настройки. **AI-ключи и пользовательский адрес AI-сервера в неё не входят.**

### Если расширение установлено из папки

1. Скачайте пакет нового выпуска для того же браузера.
2. Распакуйте его и замените содержимое **той же папки**, из которой установлено расширение. `manifest.json` должен остаться на прежнем уровне, без лишней вложенной папки.
3. Откройте страницу расширений по [таблице адресов](#chromium).
4. На карточке NMO Helper нажмите **↻ «Перезагрузить» / Reload**.
5. Обновите страницу НМО и проверьте номер версии.

Не удаляйте старое расширение без необходимости: переустановка или смена идентификатора могут повлиять на сохранённые настройки. [Пример перезагрузки расширения в Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#reload-the-extension).

### Если установлен CRX или временное дополнение Firefox

- **Яндекс / CRX:** скачайте новый CRX из выпуска и повторите установку на `browser://tune`. Если браузер не принимает обновление, сначала сохраните копию данных, затем проверьте текст ошибки.
- **Firefox / временная установка:** замените файлы выбранной сборки и нажмите **«Перезагрузить»** у дополнения в `about:debugging`. После перезапуска браузера снова выберите `manifest.json`.

### Как восстановить копию

**«База» → «Управление данными» → «Восстановить копию»** → выберите сохранённый JSON → подтвердите действие → обновите страницу НМО.

При восстановлении записи добавляются к существующим, а противоречия сохраняются для проверки. Автопрохождение после применения восстановленных настроек выключено; нужный режим выбирайте вручную.

<a id="troubleshooting"></a>
## 🛠️ 7. Частые ошибки

| Что произошло | Что проверить / сделать |
|---|---|
| Не вижу **Assets** | Откройте страницу **Releases**, а не список исходников; прокрутите выпуск вниз и раскройте Assets |
| «Не удалось загрузить manifest» / «Файл манифеста отсутствует» | ZIP должен быть распакован. В Chromium выберите именно папку, непосредственно содержащую `manifest.json` |
| Нет кнопки «Загрузить распакованное» | Включите **«Режим разработчика»** на странице расширений. F12 эту кнопку не добавит |
| «Неподдерживаемая версия манифеста» | Проверьте браузер, его версию и выбранную сборку. Старый Chromium может требовать обновления; для Firefox 102–139 выбирайте `firefox-esr` |
| В Firefox «Дополнение повреждено» или не удалось проверить подпись | Убедитесь, что не пытаетесь постоянно установить `unsigned.xpi`. Для текущего выпуска используйте временную загрузку по инструкции выше |
| Дополнение Firefox пропало после перезапуска | Это ожидаемо для временной установки. Повторите загрузку через `about:debugging` |
| Значок есть, но панели на НМО нет | Проверьте, что расширение включено, откройте нужную страницу НМО и обновите её. Ищите также свёрнутую плашку |
| «Тест не определён» | Панель загрузилась, но вопрос ещё не найден. Откройте страницу теста с вариантами; если надпись осталась, запустите диагностику |
| Появились две панели | Отключите другую установленную копию NMO Helper и обновите страницу |
| Расширение перестало работать после перемещения папки | Верните установленную папку на прежнее место либо заново загрузите её; перед переустановкой сохраните доступные данные |
| Установка запрещена администратором | Обратитесь к IT-администратору организации; не меняйте служебные политики самостоятельно |
| Поиск ничего не нашёл | Это не обязательно ошибка установки. Проверьте **«База» → «Состояние источников»**, формулировку вопроса и доступность сети |
| GitHub недоступен при проверке обновлений | Повторите позже. Недоступность проверки не означает, что установлена последняя версия |
| После завершения теста страница НМО зависла | Нажмите «Стоп» и обновите страницу. Если повторяется, приложите диагностику к сообщению об ошибке |

<a id="help"></a>
## 🧹 8. Удаление и помощь

### Как удалить

Сначала экспортируйте нужные данные. В Chromium-браузере откройте страницу расширений и нажмите **«Удалить»** на карточке NMO Helper. В Firefox используйте **«Удалить»** в `about:debugging` для временного дополнения; обычные установленные дополнения управляются через `about:addons`.

### Как сообщить об ошибке

1. В панели откройте **⚙ → «Проверить расширение»**.
2. Запишите ОС, точную версию браузера и версию NMO Helper.
3. Опишите действие и результат: например, «выбрал папку chromium, появилось сообщение…».
4. Создайте сообщение в **[GitHub Issues](https://github.com/Samyray24/nmo-helper/issues)**. Прикрепите текст ошибки или скриншот без личных данных.
